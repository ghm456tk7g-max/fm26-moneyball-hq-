# Roadmap

## Phase 0 - Foundation
- repository structure
- desktop shell decision and build pipeline
- local database and migrations
- automated tests
- Windows CI/build artifact

## Phase 1 - Import that never gets in the way
- drag/drop FM export
- delimiter/encoding detection
- English/German aliases
- column mapper fallback
- preview, validation and import report
- normalized player model

## Phase 2 - Moneyball engine
- percentile normalization by relevant comparison group
- minutes/sample-size confidence
- Performance / Value / Financial / Development / Role Fit / Confidence scores
- transparent weighting configuration
- Hidden Gem and risk tags
- deterministic tests

## Phase 3 - Recruitment workspace
- player table
- advanced filters
- shortlist
- 2-5 player comparison
- recommendation explanations

## Phase 4 - Squad intelligence
- own squad dataset
- depth chart
- weak-role detection
- target-vs-incumbent improvement

## Phase 5 - Transfer Decision Engine
- transfer budget and wage constraints
- first-year cost and total contract cost
- max bid / max wage
- BUY / CONSIDER / WATCH / PASS
- transfer-window optimization without pretending uncertain estimates are exact

## Phase 6 - Windows release hardening
- signed/reproducible release process where feasible
- installer
- desktop shortcut
- clean Windows VM smoke test
- backup/restore
- crash logging with local privacy-first logs

## Later candidates (only after core proves useful)
- league-strength calibration
- richer contract centre
- transfer-history ROI
- season-level recruitment performance

## Removed from product scope
- Match Analysis
- Manager Chronicle
- FMF LAB
