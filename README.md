# FM26 MONEYBALL HQ

Private Windows desktop recruitment and transfer-intelligence application for Football Manager 26.

## Product focus

FM26 MONEYBALL HQ is deliberately focused on the workflows that create the most value during a save:

1. Import Football Manager player exports.
2. Automatically map and normalize columns.
3. Score players for performance, value, finances, development, role fit and data confidence.
4. Detect hidden gems and shortlist targets.
5. Analyse squad weaknesses and depth.
6. Recommend transfer targets with transparent max-bid, max-wage and total-cost logic.

Out of scope for the first product version: match analysis, manager chronicle and experimental FMF parsing.

## Delivery target

The final Windows release must satisfy: **Install -> double-click -> application runs**. The end user must not install Python, Node.js, npm, Visual Studio or a separate runtime.
